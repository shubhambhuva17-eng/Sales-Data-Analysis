# Sales Data Analysis GUI Dashboard

## Features

- Monthly Sales Analysis
- Best Selling Product
- Bar Chart
- Pie Chart
- Total Sales
- Total Quantity Sold
- Best Month
- Refresh Dashboard
- CSV based data analysis

## Project Structure

Sales_Data_Analysis_GUI/
    app.py
    requirements.txt
    README.md
    data/
        sales_data.csv

## Installation

Open PowerShell in this project folder:

    pip install -r requirements.txt

## Run

    python app.py

## Important

Keep `sales_data.csv` inside the `data` folder.
